### 🌟 Projet Phare : Suite d'Automatisation Arvea Nature Tunisie

> **Dépôt de Production :** [github.com/Tilisi/Agent-AREVA-](https://github.com/Tilisi/Agent-AREVA-)  
> **Bot Telegram de Commande :** [@orchestre_tilisi_bot](https://t.me/orchestre_tilisi_bot)

Une suite complète d'automatisation commerciale, de gestion de prospects et de prise de commande **100% Zéro-Coût** s'exécutant sur terminal Android (Termux) avec un niveau de durcissement architectural de type militaire.

```
+-----------------------------------------------------------------------------------+
|                     ARCHITECTURE D'ORCHESTRATION ARVEA NATURE                     |
+-----------------------------------------------------------------------------------+
|  [ Client / Prospect ]                                                            |
|       │           │                                                               |
|       │ (Web Form)│ (Derja/FR Bot)                                                |
|       ▼           ▼                                                               |
|  [GitHub Pages] [Telegram Bot API v20+ Async] <---> [Watchdog Immortel Termux]    |
|       │                   │                                                       |
|       ▼                   ▼                                                       |
|  [Google Apps Script] ---> [ Moteur CRM SQLite3 (WAL Mode + Pragma Sync Full) ]    |
|       │                   │                                                       |
|       │                   +---> [Meta WhatsApp Cloud API] (Confirmation & Template)|
|       │                   +---> [Gmail SMTP SSL Async Pool] (Rapport KPI Journalier)|
|       ▼                   ▼                                                       |
|  [Google Sheets]     [Terminal CLI Dashboard] (Tabulate Live Analytics)           |
+-----------------------------------------------------------------------------------+
```

#### Points Forts du Projet :
- **Moteur Transactionnel SQLite3** : Mode WAL, intégrité vérifiée à chaud et persistance blindée.
- **Bot Telegram Asynchrone Bilingue** : Parcours client conversationnel fluide en **Arabe Tunisien (Derja)** et en Français.
- **Routage de Secours Draconien (OODA Loop)** : Fallback automatique en cascade en cas de défaillance réseau ou d'expiration de token.
- **Coffre-fort & Autodestruction** : Dump nocturne chiffré en AES-256 et bouton d'urgence `/code_red_destroy_all` (nettoyage militaire en 7 passes).
